# Anatomy Quiz Application

## Overview
The Anatomy Quiz Application is an interactive quiz designed to test and enhance your knowledge of human anatomy. The application presents a series of questions, each with multiple-choice answers, and provides educational explanations for the correct answers. The quiz features a biology-themed design to create an engaging learning experience.

## Features
- **Single Question Display**: Each question is presented on a separate screen, allowing users to focus on one question at a time.
- **Score Progression**: Users can track their score and progress throughout the quiz.
- **Educational Explanations**: After answering each question, users receive detailed explanations for the correct answers to enhance their understanding.
- **Responsive Design**: The application is designed to be user-friendly and responsive across different devices.

## Installation
1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd anatomy-quiz-app
   ```
3. Install the dependencies:
   ```
   npm install
   ```

## Usage
To start the application, run:
```
npm start
```
This will launch the quiz application in your default web browser.
